HTML viewer: rendering a map and navigating map ↔ diagram ↔ guide

How renderHtml() turns a map JSON document into a single self-contained HTML file, and how that file's inline script lets a user click through the sidebar tree, jump via guide references, use Prev/Next or arrow keys, and flip to a clickable Mermaid diagram that jumps back into the same node. Key takeaway: there is exactly one navigation primitive, select(id) in html.js, and every other interaction (sidebar clicks, guide [refs], nav buttons, keyboard, and Mermaid node clicks via window.mapSelect) is just a different trigger that calls it.
